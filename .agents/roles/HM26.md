# HM26 development roles

The four Agency Agents files below are **reference checklists**, not independent agents or executable tools. Select only the roles relevant to the task, read their source files when needed, and apply the useful parts in the context of HM26. The role authors' claims of experience, sample code, mandatory processes and metrics are not evidence about this project. Do not claim independent review or tests that did not happen.

Priority is: platform and user instructions, the rules below, then applicable upstream suggestions. For security reviews, the existing Cloudflare skill in `.agents/skills/security-audit/SKILL.md` remains the security-specific guide and its isolation and independent-verification requirements must not be weakened.

## Project guardrails

- HM26 is an offline-first, single-player Turkish football-management PWA using React, TypeScript, Vite, Phaser and IndexedDB. Do not assume a server, live telemetry, monetization, new external dependencies or online access is needed.
- Keep existing careers compatible. Do not add persistent fields or change the save version without the user's approval; preserve the 256-match archive limit.
- Do not introduce an 18-subattribute system or unnecessary role/mechanic complexity. Base career stories, player details and match outcomes on actual existing data; do not invent missing facts.
- Keep the final-whistle screen available until the player chooses to continue. For transfer presentations: below 80 uses the press room, 80–84 the stadium, and 85 or above the larger star stadium presentation, including free transfers.
- Honor Turkish dialogue preferences and player-selected responses; indicate negotiation risks/benefits and keep their effects small. Preserve existing classic interview texts.
- Preserve the game's visual character: transfer negotiations, signings, presentations and interviews each have their own atmosphere, using the simple, non-realistic art style of the stadium arrival. Respect reduced-motion, audio preferences and subtitles.
- Keep PRs open and do not automatically merge them. Do not deploy to production without user approval. Report what was actually tested and any remaining limitations.

## Role routing

### Game Designer — match, transfers, economy and player decisions
Source: `agency-agents/game-development/game-designer.md`

Use it to examine the player's decisions, balance, feedback and edge cases. Treat numerical ideas as hypotheses; prefer bounded simulations or checks using existing game data. Do not add gameplay systems, data fields, monetization or automatic transitions merely because an upstream template suggests them.

### UI Designer — visual consistency, mobile layouts and interaction
Source: `agency-agents/design/design-ui-designer.md`

Use it for hierarchy, consistent theming, mobile layouts and accessible controls. Fit changes to the existing React/Phaser game and its current visual style. Check narrow screens, both themes, reduced motion and audio controls where relevant; do not replace existing visuals or import unrelated design systems by default.

### Narrative Designer — Turkish scenes, interviews and dialogue
Source: `agency-agents/game-development/narrative-designer.md`

Use it to improve natural voice, choice clarity, continuity and variety. Ground career history in saved events; keep existing interview text and player agency intact. Do not add persistent story state, fictional match results, dialogue telemetry or mandatory story branches.

### Test Automation Engineer — regression coverage and evidence
Source: `agency-agents/testing/testing-test-automation-engineer.md`

Use it to select meaningful tests, isolate test data, prefer reliable selectors and report failures honestly. When relevant, cover old saves, invalid imports, write failures, restoration, multi-version offline updates, manual match transitions and the transfer thresholds. Browser, audio or assistive-technology behavior is only confirmed when actually tested. Adjust upstream rules such as fixed repeat counts to the task and environment rather than pretending they were met.
